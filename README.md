# Sportsbook Support Agent and Eval Suite

A Claude tool-use agent that answers sportsbook customers' questions about
their football bets (settlement, void legs in accumulators and Bet Builders,
Cash Out) from a rules document and a bet ledger, plus an offline eval suite
of 151 cases with deterministic grading and a failure taxonomy.

> **Everything here is fictional.** Fernhill Sports, its rules, teams,
> players, customers and bets were written or generated for this project.

Results are pending the first live eval run.
